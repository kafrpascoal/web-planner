# Web Planner 📝
Personal web planner project built with HTML and CSS

## Sobre o projeto
Este projeto é um **Web Planner** desenvolvido como parte do meu portfólio.  
Ele utiliza apenas **HTML e CSS** para criar uma interface de planejamento visual, organizada em **blocos de notas, agenda, calendário e um planner semanal**, com estilo de “caderno” e layout agradável.  
O projeto foi feito com foco em **design limpo, organização de conteúdo e responsividade básica**.

---

## Funcionalidades
- 📌 Layout visual de **planner** dividido em seções: notas, agenda, calendário e planner semanal
- 🖌 Estilização com cores suaves, bordas arredondadas, sombras e efeito de “linhas de caderno”  
- 📱 Responsividade básica, mantendo a legibilidade em diferentes tamanhos de tela  

---

## Tecnologias utilizadas
- **HTML5** – Estrutura semântica do site  
- **CSS3** – Estilização e layout com flexbox, cores, sombras, bordas arredondadas e responsividade  

---

## Estrutura do projeto
- `index.html` – Página principal com o layout do planner  
- `style.css` – Arquivo de estilos que controla cores, blocos, sombras, linhas e responsividade
